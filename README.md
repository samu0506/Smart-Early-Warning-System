# 🎓 Smart Early Warning System

A Django-based web application designed to analyze student academic performance and identify students who may be at academic risk. The system helps educators monitor student progress, generate reports, and take timely action to improve learning outcomes.

---

## 📌 Project Overview

The **Smart Early Warning System** is a web-based application developed using the Django framework. It enables educational institutions to manage student records, monitor academic performance, and identify students who require additional support through early risk detection.

The project aims to help teachers and administrators make informed decisions by providing performance insights and organized student data.

---

## ✨ Features

- 🔐 Secure User Authentication
- 👨‍🎓 Student Registration & Management
- 📊 Student Performance Dashboard
- ⚠️ Academic Risk Prediction
- 📈 Attendance Monitoring
- 📝 Student Profile Management
- 🔑 Password Reset & Change Password
- 📋 Student List with Search & Management
- 📑 Performance Reports

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/samu0506/Smart-Early-Warning-System.git
```

2. Navigate to the project directory

```bash
cd Smart-Early-Warning-System
```

3. Create a virtual environment

```bash
python -m venv venv
```

4. Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

5. Install dependencies

```bash
pip install -r requirements.txt
```

6. Apply migrations

```bash
python manage.py migrate
```

7. Run the development server

```bash
python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```
